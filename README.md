# Space Arkanoid

Projeto Unity do jogo Arkanoid com tema espacial.

## Controles
- **Seta esquerda / Seta direita**: movimentam a barra.
- **A / D**: também movimentam a barra.
- **Mouse**: mova o cursor horizontalmente dentro da janela Game para controlar a barra.

Clique dentro da janela **Game** antes de usar o teclado.

## Fluxo
Menu inicial -> Scene1 -> Scene2 -> Vitória/Derrota.
